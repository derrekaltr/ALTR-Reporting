# Examples

Four finished reports, each as the builder script that produced it plus the PDF. Read the PDF for what good
looks like; read the builder for how the content was structured. These were run on Antonio's machine, so they
are frozen references rather than scripts to re-run; the portable version of everything they do is in `lib/`,
and `lib/report_skeleton.py` is these builders with the design moved out into `lib/premium.py`.

| Folder | What | Audience | Pages | Numbers from |
|---|---|---|---|---|
| `luce-account-review` | Transition audit across two pages (VIP and free): revenue shape, hourly blasts, recycled script, top three threads, notes left to rot, dead funnel, five changes | Creator | 10 | Derrek's diagnostic |
| `alanna-account-review` | Account review: visits collapse, blast open rate, recycled opener, $199 PPV ladder, top spenders with their notes | Creator | 9 | Derrek's diagnostic |
| `vale-top-fans` | Top-fan review: OG Ry's story, top 24 ledger, four quiet fans, the $200 ceiling, timing, 30-day plan. Web and PDF from one source | Creator | 5 | Live API, 150-day ledger and 25 threads |
| `yuni-chatting-analysis` | 30-day chatting analysis across a chat-team handover: DMs per day, unlock rate by band, resends, blasts, reply times, open customs, compliance, asks for the model | Internal | 12 | Live API |
